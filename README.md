# gallary8 — Neural Monitor

Cinematic scroll-driven 3D neural field. Dark navy void, luminous point-cloud brain, GSAP ScrollTrigger storytelling.

## Stack

Next.js · TypeScript · Tailwind CSS · Three.js · React Three Fiber · GSAP ScrollTrigger

## Local

```bash
npm install
npm run dev
```

## Production (GitHub Pages)

```bash
npm run build:pages
```

Static output lands in `out/`. Live: https://hrnordleads-sso.github.io/gallary8/
